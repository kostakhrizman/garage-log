# Garage Log

Service tracker for two cars: a 2017 SEAT Ateca and a 2016 SEAT Ibiza.

- Pick a car, then drag the 3D model to turn it.
- Tap the hood to open it, then tap a part to log a replacement (date, km, cost, note).
- The table lists every part with when it was last replaced and when it's next due.

It's a single `index.html` with no build step. When it's hosted on GitHub Pages, records are saved in the phone's browser storage.
